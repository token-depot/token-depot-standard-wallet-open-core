This page is for KCC20 / OMA L1 issue and burn only. It does not replace the existing KRC-20 Issue/Burn page.

Definition of Terms
Tracked Token
A live-chain-verified OMA L1 token record from wallet Holdings. Stored records are candidates only and must re-verify before use.
Issue Holder Tokens
Spends the current controller output, creates the next controller output, and creates a new holder-token output.
Burn Holder Tokens
Spends holder-token output(s), removes the burned raw amount, and creates sender-change only when needed.
RAW Amount
Token amount in raw units. Human display uses RAW ÷ 10^decimals.
