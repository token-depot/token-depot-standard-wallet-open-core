Definition of Terms
Token Name
Human-readable token name shown throughout the wallet. Maximum 64 characters; spaces are allowed.
Token Symbol
Short ticker shown in wallet Holdings and Covenant Tools. Use 2–16 characters, A–Z and 0–9 only; no spaces.
Decimals
Display precision from 0–18. RAW amount = human amount × 10^decimals.
Max Supply (RAW)
The fixed positive issuance cap for the token. Zero is not unlimited and is rejected. Burns reduce issued supply, not this cap.
Initial Issue (RAW)
Optional amount issued to the active wallet during deployment. When zero, the token is deployed with no circulating supply.
Controller Carrier
The controller output carries 1 KAS by default. The wallet verifies the completed transaction and calculates the required fee automatically.
Holder Carrier
The initial token-holder output carries 1 KAS by default when Initial Issue is greater than zero.
Transfer Rules
Standard KCC20 transfers require the token owner’s signature.

Waiting for wallet status.

License guard
