KRC-20 Asset Registration

Use this page to either deploy a new token or import an existing CA into the Compliance Wallet registration system.

  1. Deploy mode spends 1000 KAS and requires sufficient KAS balance.
  2. Mainnet deploy still requires the wallet holdings license token gate already enforced by the app.
  3. Import mode does not deploy on-chain; it registers an existing CA for local wallet use and later broker mapping.
  4. Energy Token Lock reserves a token for the Energy page. On deploy, checking it forces Pre-Issue Amount (RAW) to 0. On import, checking it requests a post-import Energy lock test; import still succeeds even if the lock test fails.
Definition of Terms
Page Mode
Deploy New Token creates a new issue-mode token. Import Existing CA registers an already-existing contract address.
Name (A–Z), 4–6 Characters
Used only for deploy mode. Issue-mode allows duplicate names; the CA remains unique.
Decimals (0–18)
How many decimal places the token supports. RAW = human × 10^dec.
Max Supply (RAW)
Total supply cap in RAW units (human × 10^dec).
Pre-Issue Amount (RAW)
Optional initial amount to issue at deploy time, in RAW units. If Energy Token Lock is checked during deploy, pre-issue is forced to 0.
Energy Token Lock
Requests that the token be reserved to the Energy page. For deploy, the lock is applied directly after successful deploy/registration. For import, the token is imported normally first, then a post-import Energy lock eligibility test is run; if that test fails, the import still succeeds and only the lock is not applied.
Issue-To Address
Optional Kaspa address that receives the pre-issued amount when pre > 0.
Contract Address (CA)
Used only for import mode. Must be the existing 64-character CA you want to register.
Owner / Issue Address
Optional for import mode. If provided, the imported asset may participate in in-app issuable behavior; if omitted, it remains non-issuable in-app.
Network
Target Kaspa network for deploy or import.
