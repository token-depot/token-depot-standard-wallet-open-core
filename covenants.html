Base KAS Protection

Protect KAS

Transfer KAS into a covenant-bearing output so normal KAS send cannot accidentally spend it.

Policy: The selected holder wallet receives protected KAS. The active holder can release it back to native KAS.

  • Metadata saved: holder address, amount, source outpoint, covenant ID, submit txid, release txid, release output.
  • Normal KAS send remains blocked while the output is covenanted.

Policy Locks

        

          

            
              
Absolute Time Lock KAS

              
Lock KAS until a DAA target is satisfied, then release by owner signature.

            
            

              
Policy: Release is blocked until the configured absolute DAA target is reached.

              
  • Metadata saved: owner address, start/current DAA, lock target DAA, target satisfied flag, source outpoint, covenant ID.

              

                
                
                

                  
                  
                

                

                
                
                
                

                  
                  
                

                
Ready. Build the lock, then release only after the displayed DAA target is satisfied.

                

              

            

          


          

            
              
Relative Sequence Lock KAS

              
Lock KAS until the source output ages by the configured relative DAA amount.

            
            

              
Policy: Release input must carry the required sequence and the source UTXO must be old enough.

              
  • Metadata saved: relative DAA delta, source block DAA, unlock DAA, current DAA, target satisfied flag.

              

                
                
                

                  
                  
                

                

                
                
                

                  
                  
                

                
Ready. Build the lock, then release after the source has aged by the configured relative DAA delta.

                

              

            

          


          

            
              
Allowed Destination KAS

              
Lock KAS so release can pay only the configured destination address.

            
            

              
Policy: Release transaction must have one output and output 0 must use the allowed destination scriptPublicKey.

              
  • Metadata saved: owner address, allowed destination, source outpoint, covenant ID, release txid.

              

                
                
                

                  
                  
                

                

                
                
                

                  
                  
                

                
Ready. Build the lock, then release only to the configured destination.

                

              

            

          

        

      


      

        
Recovery / Commerce

        

          

            
              
Immediate Recovery KAS

              
Lock KAS so either the owner wallet or recovery wallet can release immediately.

            
            

              
Policy: Owner signature OR recovery signature can release the protected KAS.

              
  • Metadata saved: owner address, recovery address, viewer role, source outpoint, covenant ID, release path.

              

                
                
                

                  
                  
                

                

                
                
                

                  
                  
                

                
Ready. Build the lock, then release with the owner or recovery wallet as permitted.

                

              

            

          


          

            
              
Escrow / Refund KAS

              
Buyer-funded KAS can release to seller, or refund to buyer after the timeout DAA.

            
            

              
Policy: Seller release pays the configured seller address. Buyer refund pays the buyer/refund address after the configured DAA timeout.

              
  • Metadata saved: buyer/refund address, seller address, refund target DAA, source outpoint, covenant ID, release/refund path.

              

                
                
                
                
                
                

                  
                  
                

                

                
                
                

                  
                  
                  
                  
                

                
Escrow / Refund KAS is ready. Build an escrow, then use its exact source outpoint and covenant ID for seller release or buyer refund.

                

              

            

          

        

      


      

        
Combination Policies

        

          

            
              
Time Lock + Allowed Destination KAS

              
Release is allowed only after the DAA target and only to the configured destination.

            
            

              
Policy: Owner signature plus absolute DAA lock plus output 0 destination constraint.

              
  • Metadata saved: owner, allowed destination, lock target DAA, current DAA, source outpoint, covenant ID.

Owner Release + Delayed Recovery KAS

              
Owner can release immediately; recovery wallet can release only after the configured DAA target.

            
            

              
Policy: Owner signature releases immediately. Recovery signature releases only after the configured absolute DAA target.

              
  • Metadata saved: owner address, recovery address, recovery target DAA, current DAA, source outpoint, covenant ID, release path.
