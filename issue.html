KRC-20 Issue

Submit a KRC-20 Issue-Mode action for an existing token. The deploy transaction ID is the Contract Address (CA).

Definition of Terms
Contract Address (CA)
The deploy transaction ID of the Issue-Mode token.
Amount (RAW)
Amount in RAW units (human amount × 10^dec; digits only).
Issue-To Address
Kaspa address (prefix kaspa:) used in ISSUE mode only.
